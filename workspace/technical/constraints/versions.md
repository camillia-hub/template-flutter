# Version constraints

| Component | Pinned version | Notes |
| --- | --- | --- |
| Flutter | 3.35.x stable | Pinned via FVM (`.fvmrc`); CI uses the same pin. |
| Dart | 3.9.x | Comes with the Flutter pin. |
| Android | minSdk 24, target/compileSdk 36 | Gradle via the committed wrapper. |
| iOS | deployment target 15.0 | Xcode 16 on CI. |
| Riverpod | 2.x with `riverpod_generator` | Providers are generated by build_runner at build time. |

Dependencies upgrade on the release train: bumps land on `main` right after a
release cut, never during the freeze.
