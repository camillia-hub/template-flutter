# Business glossary

The skeleton below uses a ride-hailing example domain; replace it with your own
during workspace setup. Use these terms in code, UI copy and conversations.

| Term | Definition |
| --- | --- |
| Rider | The end user of the app. |
| Trip | One journey from pickup to drop-off; the core record. |
| Fare | The price of a trip, estimated before booking and finalized after. |
| Release train | The fortnightly shipping cadence of the app. |
| Feature flag | A toggle gating unfinished functionality. |
| Store listing | The app's page on Google Play or the App Store. |
